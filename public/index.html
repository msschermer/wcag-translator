Input

plain language
Describe the behaviour you can see, and name the element. “The submit button reads as unlabelled” lands better than “fix aria”.
axe-core and Lighthouse ids resolve from the mapping table. Pa11y and HTML_CodeSniffer codes are parsed directly, since they carry the criterion inside them. Comma separate up to 100.
Paste axe results JSON, a Lighthouse LHR, Pa11y JSON, or a plain array of rule ids. The format is detected from the shape. Element counts and impact carry through to each criterion.
All three namespaces are searched at once, so 1.4.3, contrast-minimum, H37 and “accessible name” all work without picking a type first.

Matching runs on this server against the indexed W3C data.

Response

idle

Send a description, a checker rule id or a whole scan report. You get back the success criteria it maps to, why each one matched, and where the wording came from.

    Endpoints

    • POST /v1/translateLanguage to criteria, with match basis and confidence.
    • POST /v1/translate/ruleChecker rule ids. Same result shape. Up to 100 per call.
    • POST /v1/reportA whole axe, Lighthouse or Pa11y report, rolled up by criterion.
    • GET /v1/coverageWhich criteria automation reaches, and which need a person.
    • GET /v1/search?q=Ranked search across criteria, techniques and glossary.
    • GET /v1/criteria/:idOne criterion, plus /coverage and /related.
    • GET /v1/techniques/:idOne technique, and the criteria it supports.
    • GET /v1/glossary/:termA WCAG glossary definition.
    • GET /v1/rulesEvery checker rule this build knows, filterable by criterion.
    • GET /v1/healthLiveness, plus the age of the indexed W3C data.

    How much of WCAG automated tooling reaches on its own.

    • — automated An engine publishes a rule claiming this criterion, so a scanner can find some of its failures.
    • — assisted Reached only by a manual prompt, or by a mapping this service supplies. Local mappings never count as engine coverage.
    • — human review A person decides this one. Most of WCAG lives here, which is the number worth knowing before trusting a green CI badge.
